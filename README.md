# IA, droit d'auteur et droit de la preuve

This repository hosts a public research thesis on AI, copyright and proof.

The document does not propose a technical solution.
It provides a legal and structural analysis of why, without a probative infrastructure,
copyright law struggles to remain effective at AI scale.
